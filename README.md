# Arena

Roblox-игра «все против всех»: круглая арена, 4 боевых приёма, энергия («Aura»), счётчик убийств.
Арена и вся логика строятся кодом, поэтому проект лежит в git как обычные файлы и удобен для работы вдвоём.

> Все названия, приёмы и внешний вид в игре **оригинальные**. Не добавляйте в игру персонажей, имена
> и картинки из чужих аниме/игр: на такие проекты приходят жалобы правообладателей и их банят.

## Управление

| Клавиша | Приём | Что делает | Aura | Перезарядка |
|---|---|---|---|---|
| ЛКМ | Strike | ближний удар перед собой | 0 | 0,45 с |
| Q | Blast | снаряд в точку курсора | 25 | 3 с |
| E | Dash | рывок в сторону курсора | 15 | 4 с |
| R | Shockwave | взрыв вокруг себя, отбрасывает всех | 50 | 10 с |

Aura восстанавливается сама. Убийство даёт +1 в таблице `Kills`. После смерти возрождение через 3 секунды
со спавн-защитой. Все числа лежат в [`src/ReplicatedStorage/Shared/Config.luau`](src/ReplicatedStorage/Shared/Config.luau).

## Структура

```
default.project.json                          # карта Rojo: что куда попадает в Studio
src/ReplicatedStorage/Shared/Config.luau      # баланс: урон, откаты, стоимость
src/ServerScriptService/BuildArena.server.luau # строит арену (пол, стены, колонны, 10 спавнов)
src/ServerScriptService/Combat.server.luau    # бой на сервере: приёмы, урон, кредит за убийство
src/StarterPlayer/StarterPlayerScripts/Input.client.luau  # клавиши, интерфейс, рывок и отбрасывание
src/StarterPlayer/StarterPlayerScripts/Effects.client.luau # пиксельные спрайты: снаряд Blast и взрыв при попадании
assets/fx/blast/                              # исходники эффектов (pixelfx, MIT) и листы 8x8 для загрузки в Roblox
legacy/obby/                                  # старый прототип обби, не синхронизируется
```

## Как запустить

1. Поставь [Rojo](https://rojo.space/docs/v7/getting-started/installation/) и плагин Rojo для Studio.
2. В папке репозитория выполни `rojo serve`.
3. Открой в Studio пустой place, в плагине Rojo нажми **Connect**.
4. Нажми **Play**: арена строится сама. Для проверки боя на двоих: *Test → Clients and Servers → Players: 2*.

## Как работать вдвоём

- Работайте в **ветках** и делайте pull request, не пишите оба в `main`.
- Делите файлы: один правит `Combat` (приёмы, урон), другой `BuildArena` и `Input` (карта, интерфейс).
- Меняйте игру только в файлах из `src/`: то, что вы руками поставили в Studio, в git не попадёт.
- Файлы `*.rbxl` в git не кладём (они бинарные), см. `.gitignore`.

## Эффекты

Снаряд Blast и его взрыв нарисованы пиксельными спрайтами из библиотеки [pixelfx](https://pixelfx.io) (лицензия MIT,
уведомление лежит в `assets/fx/blast/`). Листы 1024x1024 (сетка 8x8, кадр 128x128) загружены в Roblox,
их id записаны в `Config.Effects`. Чтобы заменить эффект: пересоберите лист в такую же сетку, загрузите в Roblox
(Studio → Asset Manager или MCP `upload_image`) и поменяйте id в `Config.Effects`. Кадры листает клиент
(`Effects.client.luau`), сервер только помечает снаряд тегом `BlastOrb` и шлёт событие `BlastHit`.
