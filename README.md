# Obby

Простая игра-обби для Roblox. Трасса строится кодом при запуске игры, поэтому весь проект
лежит в git как обычные файлы и над ним удобно работать вдвоём.

**Этапы:** прыжки по платформам → камни над лавой → лестница вверх → балка и красные полосы → финиш.
Есть чекпоинты, счётчики `Stage` и `Wins`, смерть на лаве и красных полосах.

## Структура

```
default.project.json                       # карта Rojo: что куда попадает в Studio
src/ServerScriptService/
  BuildObby.server.luau                    # строит трассу (платформы, лава, чекпоинты, финиш)
  ObbyScript.server.luau                   # логика: смерть, чекпоинты, Stage/Wins, финиш
```

## Как запустить

1. Поставь [Rojo](https://rojo.space/docs/v7/getting-started/installation/) и плагин Rojo для Studio.
2. Склонируй репозиторий и в его папке выполни:
   ```bash
   rojo serve
   ```
3. Открой в Roblox Studio пустой place (Baseplate), нажми в плагине Rojo **Connect**.
4. Нажми **Play**. Трасса построится сама.

## Как работать вдвоём

- Работайте в **ветках** и делайте pull request, не пишите оба в `main`.
- Лучше делить файлы: один правит `BuildObby`, другой `ObbyScript`, чтобы не ловить конфликты.
- Меняйте игру только в файлах из `src/`. То, что вы руками поставили в Studio, в git не попадёт.
- Файлы `*.rbxl` в git не кладём (они бинарные), см. `.gitignore`.
